# Ця тека — копія, а не сайт

`yesplate.app` публікується **не звідси**. Його віддає GitHub Pages з
окремого відкритого репозиторію:

    https://github.com/ielizavetagladko-cloud/yes-plate-site

Гілка `main`, корінь репозиторію, домен у CNAME. DNS живе в Porkbun і
вказує на адреси GitHub Pages.

**Правка тут на сайт не потрапляє.** Я на цьому вже спіткнувся: виправив
політику приватності в `site/`, відрапортував, що зроблено, — а
yesplate.app ще тиждень показував би старий текст. Помітилося лише тому,
що я відкрив живу сторінку й порівняв.

Тому порядок такий: правити тут, а тоді перенести в той репозиторій і
запушити. Або, що чесніше, колись звести дві копії в одну.

Звірити, чи вони розійшлися:

```bash
gh repo clone ielizavetagladko-cloud/yes-plate-site /tmp/site
diff -r /tmp/site site --exclude .git --exclude README.md
```
